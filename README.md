# Flow

Master keyboard για VST3 / AU plugins (Prisma Audio).

- 16 blocks πάνω στα 88 πλήκτρα, το καθένα με δικό του plugin.
- Μια σειρά κουμπιών για το επιλεγμένο block: Block, Learn, VST, Window, Hold, Arp, και τρία κουμπιά looper (Rec/Play/Overdub, Undo, Stop).
- Δεξί κλικ σε κουμπί: ανάθεση σε MIDI πετάλι (MIDI learn).
- Οθόνη loops και plugin μέσα στο παράθυρο.
- Κλικ στο "π / -" πάνω-πάνω ανοίγει τις ρυθμίσεις ήχου και MIDI.

Το build γίνεται αυτόματα στο GitHub Actions (Actions → τελευταίο run → Artifacts → Flow-macOS).
