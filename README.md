# Flow

Master keyboard και host για VST3 / AU plugins (Prisma Audio). macOS, μόνο Apple Silicon.

- 16 blocks πάνω στα 88 πλήκτρα, το καθένα με δικό του instrument, ζώνη, hold (LM/LP), καμπύλη έντασης και transpose.
- MIDI FX (π.χ. Stepic) πριν από το instrument, αλυσίδα Audio FX ανά block και Master FX στο τελικό μίγμα.
- Rec MIDI loop με ανεξάρτητο μήκος ανά block (έως 16 μέτρα), overdub, undo και quantize (start, length, snap).
- Tempo (40-240) με tap (κουμπί ή δύο ελεύθερα μαύρα πλήκτρα), Ableton Link, metronome σε ξεχωριστή έξοδο.
- Rec Audio: master και ένα stem ανά block, όλα σε ένα zip.
- Panic, αποθήκευση και φόρτωση set (κλικ στο "π / -").
- Δεξί κλικ σε κουμπί: ανάθεση σε MIDI πετάλι ή πλήκτρο (MIDI learn).

Λήψη: GitHub → Releases (κάθε build γίνεται αυτόματα). Η εφαρμογή δεν είναι υπογεγραμμένη: την πρώτη φορά δεξί κλικ → Άνοιγμα.
